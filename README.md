# Nuvsha Docs

This repository contains the Nuvsha documentation site and source docs content.

## Project structure

- `docs/` — documentation markdown files
- `website/` — Vite + React docs website

## Run locally

```bash
cd website
npm install
npm run dev
```

## Production build

```bash
cd website
npm run build
```

## Git

This repository is ready to be pushed to a remote Git host such as GitHub.
